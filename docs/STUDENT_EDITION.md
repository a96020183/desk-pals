# 學生版桌面小隊：設計依據與範圍

這個分支沿用 Desk Pals 現有的 macOS 皮克敏桌面夥伴、專注計時、勿擾、提醒和 Codex 工作監看。學生模式把常用動作集中在「小幫手」選單；不新增背景活動追蹤或自動排課。

## 先處理的學生情境

- **作業、報告和考試準備同時逼近**：提供 25、50、90 分鐘的明確開工選項，讓人先承諾一段可完成的時間；既有「提醒我」可記上課或繳交時間。
- **社群、訊息和其他通知打斷讀書**：可手動開 30、60、120 分鐘安靜模式，也可以隨時關閉。程式不自行判斷學生正在讀書。
- **Codex 在背景跑任務**：沿用既有 Codex 監看與完成狀態。若專注期間低優先通知被暫存，專注結束時再補送，避免打斷讀書。
- **需要休息或改變節奏**：專注時間結束會沿用既有休息提示和番茄數，不因漏掉一次就扣分或懲罰。

## 為什麼先做這些

大學常見的考試、報告、實驗報告和團隊專案都有明確期限，且需要分散在一段時間完成；大學課程情境的研究也將拖延和時間管理、身心狀態連結起來。讀書時的通知與裝置切換是學生注意力管理研究反覆討論的干擾來源。休息方式因人與任務不同，因此本版採用手動、可取消的時段，而非強迫每個人照固定節奏。
